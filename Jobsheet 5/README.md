# Jobsheet 5 — JavaScript & Interaktivitas

Sub-CPMK: Menerapkan JavaScript untuk menambahkan interaktivitas pada halaman web.

## Deskripsi

Jobsheet 5 merupakan pengembangan dari Jobsheet 4.
Pada jobsheet ini, aplikasi SIMPUS-Mini mulai menggunakan JavaScript
untuk menambahkan interaktivitas pada halaman website.

JavaScript digunakan untuk membuat menu navigasi lebih interaktif,
melakukan validasi form, melakukan filter data pada tabel,
serta memberikan konfirmasi sebelum data dihapus.

## Perubahan dari Jobsheet 4

Perubahan yang dilakukan pada Jobsheet 5 meliputi:

- Menambahkan file `assets/js/app.js`.
- Mengubah hamburger menu menjadi toggle berbasis JavaScript.
- Menambahkan validasi form menggunakan JavaScript.
- Menambahkan fitur pencarian/filter pada tabel.
- Menambahkan konfirmasi sebelum menghapus data.
- Menambahkan interaksi pada halaman tanpa menggunakan backend.
