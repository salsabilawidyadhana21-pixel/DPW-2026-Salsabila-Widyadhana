# LAPORAN PRAKTIKUM
# JOBSHEET 2 – CSS3 STYLING DASAR
# A. Judul

Mengimplementasikan Styling Dasar dengan CSS3 pada Aplikasi SIMUS Mini

# B. Tujuan Praktikum
1. Memahami fungsi dan konsep dasar CSS3.
2. Menerapkan CSS pada halaman web yang telah dibuat pada Jobsheet 1.
3. Menggunakan Flexbox untuk mengatur layout header dan navigation.
4. Menggunakan CSS Grid untuk membuat komponen card.
5. Memberikan styling pada tabel, form, tombol, dan footer.
6. Membuat tampilan seluruh halaman lebih rapi dan konsisten.

# C. Dasar Teori
CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan layout halaman web. Jika HTML digunakan untuk membuat struktur halaman, CSS digunakan untuk mengatur tampilan seperti warna, ukuran, jarak, posisi, border, dan layout.

Pada Jobsheet 2 digunakan beberapa konsep CSS, yaitu box model, selector, Flexbox, CSS Grid, hover, dan styling form serta tabel.

# D. Struktur Folder 
```
simus-mini/
│
├── index.html
│
├── assets/
│   └── css/
│       └── style.css
│
├── buku/
│   ├── list.html
│   └── tambah.html
│
└── anggota/
    ├── list.html
    └── tambah.html
```

File utama yang ditambahkan pada Jobsheet 2 adalah:
```
assets/css/style.css
```

# E. Langkah Kerja 
1. Membuat folder assets/css di dalam project.
2. Membuat file style.css.
3. Menghubungkan file CSS ke seluruh halaman HTML menggunakan tag <link>.
4. Mengatur header dan navigation menggunakan Flexbox.
5. Membuat card statistik pada halaman Beranda menggunakan CSS Grid.
6. Memberikan styling pada tabel Daftar Buku dan Daftar Anggota.
7. Menambahkan zebra stripe dan efek hover pada tabel.
8. Memberikan styling pada form Tambah Buku dan Tambah Anggota.
9. Memberikan styling pada tombol dan footer.
10. Menjalankan project menggunakan Live Server untuk melihat hasilnya.

# F. Hasil Praktikum 
Setelah CSS diterapkan, halaman SIMUS Mini mengalami perubahan tampilan, antara lain:

1. Header dan navigation tersusun lebih rapi.
2. Menu navigasi menggunakan Flexbox.
3. Halaman Beranda memiliki tiga card statistik.
4. Card menggunakan CSS Grid.
5. Tabel memiliki border dan warna yang lebih jelas.
6. Baris tabel menggunakan zebra stripe.
7. Tabel memiliki efek hover.
8. Form tampil lebih teratur dan mudah dibaca.
9. Tombol memiliki warna dan efek hover.
10. Footer memiliki tampilan yang lebih rapi.
11. Semua halaman memiliki tampilan visual yang konsisten.
