# Dokumentasi Jobsheet 9

## 1. Deskripsi

Jobsheet 9 merupakan pengembangan **SIMPUS-Mini** dengan menggunakan **PHP dan database**.

Pada jobsheet ini, data buku dan anggota dihubungkan dengan database sehingga data dapat ditampilkan dan ditambahkan melalui aplikasi.

## 2. Koneksi Database

File `koneksi.php` digunakan untuk menghubungkan aplikasi dengan database.

Koneksi tersebut digunakan oleh halaman yang membutuhkan akses terhadap data database.

## 3. Data Buku

Halaman **Daftar Buku** digunakan untuk menampilkan data buku dari database.

Data buku dapat ditambahkan melalui halaman `tambah.php`, kemudian diproses menggunakan `proses_tambah.php`.

## 4. Data Anggota

Halaman **Daftar Anggota** digunakan untuk menampilkan data anggota dari database.

Data anggota dapat ditambahkan melalui halaman tambah anggota.

## 5. Pencarian

Pada halaman **Daftar Buku** terdapat fitur pencarian yang dapat digunakan untuk mencari data buku berdasarkan judul.

## 6. Tampilan

Tampilan aplikasi menggunakan CSS yang digunakan pada jobsheet sebelumnya sehingga tampilan antar halaman tetap konsisten.

## 7. Kesimpulan

Jobsheet 9 berhasil mengembangkan SIMPUS-Mini menjadi aplikasi PHP yang terhubung dengan database. Data buku dan anggota dapat ditampilkan serta ditambahkan melalui sistem.
